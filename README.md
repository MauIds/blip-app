# Blipz

Badge electrónico con una criatura pixel art (Blip) y su app de iPhone, para hacer networking en eventos: cuando dos badges están cerca hacen PING y se construye tu red de contactos por evento.

| [`docs/`](docs/) | Especificación del prototipo v1. **Empieza aquí** |
| `app/` | App de iPhone (Expo + TypeScript), desde la Fase 1 |
| `backend/` | Supabase, desde la Fase 4 |
| `firmware/` | Firmware del badge (trabajo aparte) |
| [`odd/`](odd/) | Seguimiento del trabajo con Gentle AI |
